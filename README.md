#  My Cloud — FRONTEND

Репозиторий содержит клиентскую часть веб-приложения (SPA).

---

## ☁️ Структура проекта
*   `src/` - исходный код приложения.
	* `api/`
		* `api.ts` - все запросы на backend
	* `assets/` - используемый контент
	* `components/` 
		* `FileItem.tsx` отрисовка и логика файла
		* `Navbar.tsx` отрисовка и логика навигационного меню
	* `pages/`
		* `AdminPage.tsx` 
		  * удаление пользователя
		  * изменение прав
		  * отрисовка списка юзеров и хранилищ
		* `HomePage.tsx` - стартовая страница
		* `LoginPage.tsx`  - логин (вход) пользователя
		* `RegisterPage.tsx` - регистрация нового пользователя
		* `StoragePage.tsx` 
		  * загрузка файлов
		  * удаление файла
		  * изменение файла (коммент, имя файла)
		  * скачивание файла
		  * скачивание через копирование в буфер спец. ссылки 
	* `store/` 
	* `types/`
	* `App.tsx` "мозг" проекта
	* `index.css` стили
	* `main.tsx` создание рута, рендеринг App
	* 
*   `package.json` — конфигурационный файл npm, зависимости и скрипты сборки.
*   `vite.config.ts`— конфигурация сборщика проекта.
*   `CREDITS.md` - ссылки на используемый контент.

## Инструкция по сборке и подготовке артефактов

Инструкция описывает процесс компиляции исходного кода во фронтенд-артефакты, необходимые для последующего развёртывания на веб-сервере.

### Требования к окружению
На сервере/локальной машине должен быть установлен менеджер пакетов **Node.js** 

### Процесс сборки:
1. Перейдите в корневую директорию фронтенд-проекта:
   ``cd ~/front-MYCLOUD``

2.  Установите все зависимости, указанные в `package.json`:
    ``npm install``
    
3. Запустите процесс компиляции и сборки проекта:
   ``npm run build``

_Результатом выполнения команды станет генерация папки `dist/` в корне проекта. Это и есть целевые артефакты фронтенда (HTML, скомпилированный JS, CSS)._

4.  Обеспечьте корректные права доступа к собранным артефактам, чтобы веб-сервер (например, Nginx) имел к ним доступ на чтение:
``chmod -R 755 /home/ivan/front-MYCLOUD/dist``
    
_Общая инструкция по связыванию собранного фронтенда с бэкендом и настройке веб-сервера Nginx находится в файле README.md в репозитории с бэкендом._
